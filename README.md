# Кошторис переїзду

Сторінка рахує, скільки коштуватиме перевезти речі Новою Поштою з адреси на адресу, і підказує, як запакуватися дешевше.

Сервіс неофіційний, з Новою Поштою не пов'язаний.

## Що вміє

- **Ціни з API Нової Пошти.** Пошук міст і `getDocumentPrice` працюють без ключа, CORS дозволяє запити з браузера. Сервер не потрібен.
- **Тарифна модель** (`js/model.js`). Рахує миттєво й офлайн, на ній стоять підказки. Для кожного маршруту ставки уточнюються вісьмома пробними запитами (кеш на добу). Підсумок звіряється з API. Якщо НП порахувала інакше, у розрахунку з'являється рядок «Різниця з розрахунком НП».
- **Підказки** (`js/hints.js`). Під кожним місцем і для всієї відправки, з економією в гривнях. Перелік і звідки кожна взялася — у [docs/hints.md](docs/hints.md).
- **Ощадно до API.** Приклад на першому екрані береться зі знімка, який раз на добу звіряє GitHub Action, тож перше відкриття не робить запитів. Ціна кожного місця кешується, поки відкрита вкладка: після правки одного місця решту не перепитуємо. Звірка стартує через 2 секунди після останньої правки.
- **Поділитися.** Посилання з речами й містами в `#z=…`, без адрес. Вміст стиснуто, тому посилання в кілька разів коротше; старі `#s=…` теж відкриваються. Кнопка «Скопіювати підсумок текстом» дає короткий текст.
- **Збереження.** Список зберігається в `localStorage` браузера.

## Запуск локально

ES-модулі не працюють з `file://`, тож потрібен локальний сервер. `tools/serve.py` — це той самий `http.server`, але він забороняє браузеру кешувати файли, тому після правок не видно старої версії:

```bash
python tools/serve.py
```

- Сторінка: http://localhost:8790/
- Тести: http://localhost:8790/tests/ (заголовок вкладки `PASS n/n`)

## Структура

| Файл | Що в ньому |
|---|---|
| `index.html`, `css/style.css` | розмітка і стиль «Накладна» |
| `css/fonts.css`, `fonts/` | IBM Plex Sans і Mono, лежать у репо (ліцензія OFL) |
| `js/model.js` | тарифна модель і калібрування ставок |
| `js/hints.js` | підказки для місця й відправки |
| `js/np.js` | запити до API НП, кеш ставок і цін, звірка |
| `js/snapshot.js` | знімок прикладу: ставки й суми, звірені з API (пише скрипт) |
| `tools/update-snapshot.mjs`, `.github/workflows/snapshot.yml` | раз на добу звіряє приклад з API і оновлює знімок |
| `js/state.js` | приклад, збереження, посилання |
| `js/app.js` | інтерфейс |
| `tests/` | тести моделі й підказок на цифрах, звірених з API |

Збірки немає. Хостинг — будь-який статичний (GitHub Pages).

## Приватність

Сторінка звертається лише до API Нової Пошти: туди йдуть міста, розміри, вага й оцінка місць. Назви речей нікуди не надсилаються. Шрифти й скрипти лежать у репо, сторонніх лічильників і cookies немає. Розрахунок з чужого посилання не замінює збережений список, доки його не почати редагувати.

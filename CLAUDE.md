# Кошторис переїзду — правила репо

## Заборони

- Не додавати API-ключ НП у код: сторінка публічна, ключ буде видно всім. Потрібні методи працюють з порожнім `apiKey`.
- Не використовувати логотип і фірмовий стиль Нової Пошти, не писати «novaposhta» в домені й назві. Дисклеймер «неофіційний» у підвалі не прибирати.
- Не класти в посилання (`#z=`, старе `#s=`) адреси, телефони чи імена. Там лише речі, міста й налаштування.
- Лише адреса → адреса. Відділення не показуємо навіть підказкою (рішення 13.11.2026).
- Без AI у продукті в першій версії. Без бекенду й акаунтів.

## Робочий цикл

1. Змінив тариф чи підказку — додай тест у `tests/tests.js` на цифрі, звіреній з API, і прожени `tests/` у браузері.
2. Нове правило НП міряй запитом до `getDocumentPrice`, а не з пам'яті. Дату заміру пиши в `docs/hints.md`.
3. Змінив приклад у `js/state.js` (місця, міста, галочки «До дверей») — онови `js/snapshot.js`: `node tools/update-snapshot.mjs` або запусти Action «Знімок цін прикладу» вручну. Інакше перше відкриття знову піде в API, а тест «знімок: той самий приклад» впаде.
4. Перед запитом до API сторони сортуються за спаданням. API перевіряє довжину на 120, а ширину й висоту на 70, тому без сортування ціна залежить від порядку введення.

## Граблі

- `js/snapshot.js` пише скрипт, руками не правити. Сторінка вірить знімку 14 днів; якщо Action перестав його оновлювати, вона сама повертається до живих запитів. GitHub вимикає розклад у репо без комітів 60 днів — тоді Action треба ввімкнути знову.
- Голий `python -m http.server` не шле Cache-Control, і Chrome показує старі CSS і JS після правок. Локально запускати лише `python tools/serve.py` (no-store, порт 8790; інший порт — аргументом).
- У `index.html` стоїть CSP: скрипти, стилі й шрифти лише зі свого домену, запити лише до `api.novaposhta.ua`. Інлайнові `<script>`, `<style>` і атрибут `style=""` не спрацюють. Новий зовнішній сервіс (аналітика) треба дописати в CSP.
- Шрифти лежать у `fonts/`, а не на Google Fonts: сторінка не віддає IP відвідувачів третім сторонам.
- `[hidden]` перебивається `display: flex` у класах. Глобальне правило `[hidden] { display: none !important; }` у CSS не прибирати.
- НП округлює страховку кожного місця окремо: 8000 на 6 місць = 40,02, а не 40.
- Розкладка: `<aside class="side">` (разом, розрахунок, поділитися) на телефоні має `display: contents`, а порядок блоків задає `order` у CSS. Від 1000 px це права колонка з `grid-row: 2 / span 5`, де 5 — кількість блоків лівої колонки. Додав блок у ліву колонку — збільш span і дай блоку `order`.
